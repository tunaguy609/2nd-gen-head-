# 2nd-gen-head-

OpenSCAD model files for a lure head with a 7 mm tapered nose, a 12 mm straight section, and two decorative engraved grooves.

## Files

- `/home/runner/work/2nd-gen-head-/2nd-gen-head-/config.scad` stores the tunable dimensions, including the tapered nose and straight body lengths.
- `/home/runner/work/2nd-gen-head-/2nd-gen-head-/grooves.scad` defines the groove cutters.
- `/home/runner/work/2nd-gen-head-/2nd-gen-head-/head.scad` builds the head and subtracts the grooves.

## Usage

Render `/home/runner/work/2nd-gen-head-/2nd-gen-head-/head.scad` in OpenSCAD. Adjust the nose, straight section, and groove values in `config.scad` to tune the final profile.
