# 2nd-gen-head-

OpenSCAD model files for a simple head with two decorative engraved grooves.

## Files

- `/home/runner/work/2nd-gen-head-/2nd-gen-head-/config.scad` stores the tunable dimensions.
- `/home/runner/work/2nd-gen-head-/2nd-gen-head-/grooves.scad` defines the groove cutters.
- `/home/runner/work/2nd-gen-head-/2nd-gen-head-/head.scad` builds the head and subtracts the grooves.

## Usage

Render `/home/runner/work/2nd-gen-head-/2nd-gen-head-/head.scad` in OpenSCAD. Adjust the groove values in `config.scad` to change the engraving.
