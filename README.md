# 2nd-gen-head-

OpenSCAD model work for a second-generation lure head.

## Files

- `/home/runner/work/2nd-gen-head-/2nd-gen-head-/scad/haywire_tackle_double_skirt.scad` - parametric Haywire Tackle double skirt trolling lure head

## Usage

Open the SCAD file in OpenSCAD and render/export it directly. The top of the file exposes the main configuration values and optional feature toggles for:

- leader hole
- eye pads
- grooves
- collars
